# 前端实现 AI 提示词

你负责 Vue 3 + TypeScript 前端。遵循 UI_STANDARD 和 API_CONTRACT。

要求：
- 组件化，不在页面中复制业务规则；
- 通过 typed API service 访问后端；
- 处理加载、空、错误、冲突和待确认状态；
- 360px 手机宽度完整可用；
- AI 草稿与正式数据视觉严格区分；
- UI 变更提交桌面和手机截图；
- 关键流程增加 Playwright 测试。

禁止：擅自修改 API、在 localStorage 保存正式数据、在前端保存密钥。


共同硬性规则：
- 先读 AGENTS.md、当前 Issue 和相关规范；
- 不扩大任务范围；
- 不发明产品规则；
- 任何正式数据变化必须可追溯；
- AI 结果先草稿后确认；
- 不允许通过删除测试使 CI 通过；
- 发现冲突或高风险时停止并提交决策请求。
