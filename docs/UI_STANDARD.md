# UI 与交互标准

## 1. 原型继承

当前 HTML 原型位于 `references/考研智能学习系统_V1.1_本地版.html`，是视觉和交互参考，不是正式数据架构。

保留：

- 产品名“研途教练”；
- 今日、规划、学习、进度、设置五个入口；
- 深蓝 + 蓝 + 青绿色的理性学习风格；
- 卡片、状态标签、任务解释和风险提示；
- 桌面侧栏与移动底部导航；
- “用户确认必需”“证据边界”等关键提示。

## 2. 设计令牌

原型基准：

```css
--navy: #102a4c;
--navy-2: #163b6d;
--blue: #2f6fed;
--cyan: #19a7a0;
--green: #14845d;
--yellow: #a56b08;
--red: #c0394b;
--gray-900: #162033;
--gray-100: #f4f7fb;
--radius: 18px;
```

正式工程应改为统一 token，不在组件中散落颜色和尺寸。

## 3. 页面原则

- 每页有一个主要下一步动作；
- 默认不展示内部 ID、数据库状态和技术字段；
- 卡片默认显示最必要信息，详情按需展开；
- AI 推断、用户确认和正式记录视觉上严格区分；
- 风险提示给出原因和行动，不只显示颜色；
- 图表可点击进入具体任务、知识点或错题。

## 4. 移动端

- 360px 宽度下无关键横向溢出；
- 题目、答案和附件完整可读；
- 宽表转为卡片或分组列表；
- 上传、确认和反馈按钮触控高度不小于 44px；
- 固定操作区不能遮挡正文；
- 长标题和文件名可换行，不截断关键信息。

## 5. 状态视觉

- 未学习：灰；
- 薄弱/衰退：红；
- 待巩固：黄；
- 训练中：蓝；
- 稳定掌握：绿；
- AI 草稿：黄色标签并显示“待确认”；
- 低置信度：明确显示字段和原因。

## 6. 可访问性

- 颜色不是唯一信息载体；
- 表单有 label 和错误提示；
- 支持键盘操作与可见焦点；
- 对比度满足常规可读性；
- 图标配文字或 aria-label；
- 动画尊重 `prefers-reduced-motion`。

## 7. 视觉回归

至少保存以下截图基线：

- 五个一级页面桌面版；
- 五个一级页面 360px 手机版；
- 空数据、长内容、错误、加载和 AI 待确认状态；
- 有 20+ 任务或 50+ 文件时的密集状态。
