# 核心验收矩阵

每个需求必须映射到自动测试或明确的人工验收。状态：`AUTO` 自动化；`HUMAN` 产品体验；`BOTH` 两者均需。

| ID | 需求 | 验收场景 | 合格条件 | 方式 |
|---|---|---|---|---|
| PLAN-001 | 五层规划 | 建立学期→季度→月→周→日 | 每层有真实父子关系，可追溯 | AUTO |
| PLAN-002 | 下级来源 | 查看任一每日任务 | 能追溯到周/月/季度/学期目标或明确来源 | AUTO |
| PLAN-003 | 偏差向上反馈 | 连续两日未完成周任务 | 周风险升高，并影响月风险 | AUTO |
| PLAN-004 | 不排满全天 | 可用 240 分钟生成计划 | 计划占用不超过配置上限，保留机动时间 | AUTO |
| PLAN-005 | 单科约束 | 选择“只学数学一” | 当日任务不出现 841 | AUTO |
| PLAN-006 | 精力适配 | 低精力状态生成任务 | 不安排高认知负荷综合训练 | AUTO |
| PLAN-007 | 超时拆分 | 同类任务连续超时 | 后续预计用时校准或任务拆小 | AUTO |
| PLAN-008 | 未完成诊断 | 同一任务连续三日未完成 | 不机械复制，生成原因诊断入口 | AUTO |
| TASK-001 | 任务可解释 | 打开任务详情 | 显示来源、原因、预计用时、阶段和标准 | BOTH |
| TASK-002 | 状态分离 | 完成任务但结果为“做错” | 任务状态完成，掌握不自动提高 | AUTO |
| TASK-003 | 真实反馈 | 提交结果 | 保存实际用时、完成度、正确率、把握度和问题 | AUTO |
| MAST-001 | 阅读证据边界 | 上传阅读记录 | 掌握最多到“已接触” | AUTO |
| MAST-002 | 闭卷必要性 | 无闭卷证据尝试进入“可回忆” | 拒绝推进并说明缺失证据 | AUTO |
| MAST-003 | 基础应用门槛 | 题量或正确率不足 | 不进入“基础应用” | AUTO |
| MAST-004 | 变式门槛 | 仅原题正确 | 不进入“变式应用” | AUTO |
| MAST-005 | 迁移门槛 | 无混合/综合题证据 | 不进入“综合迁移” | AUTO |
| MAST-006 | 稳定掌握 | 多时间点证据达到阈值 | 才能进入“稳定掌握” | AUTO |
| MAST-007 | 状态回退 | 稳定掌握后抽测失败 | 状态回退并生成补救任务 | AUTO |
| MAST-008 | 重复错因 | 同一深层错因再次出现 | 提高优先级并回退到相应阶段 | AUTO |
| MAST-009 | 规则版本 | 任一状态变化 | 保存判定规则版本与证据引用 | AUTO |
| REVIEW-001 | 到期复习 | 达到复习日期 | 进入候选任务并提高优先级 | AUTO |
| REVIEW-002 | 失败缩短间隔 | 间隔测试失败 | 回退且缩短下次间隔 | AUTO |
| REVIEW-003 | 连续通过延长 | 多次独立通过 | 逐步延长复习间隔 | AUTO |
| EVID-001 | 多图上传 | 上传 3 张照片 | 形成同一证据草稿，原图可追溯 | AUTO |
| EVID-002 | AI 需确认 | AI 分析完成但未确认 | 正式记录、掌握和计划不改变 | AUTO |
| EVID-003 | 不确定字段 | 识别低置信度公式 | 标记不确定并要求补充，不擅自补条件 | BOTH |
| EVID-004 | 草稿拒绝 | 用户拒绝草稿 | 不产生正式学习记录 | AUTO |
| EVID-005 | 历史管理 | 查看或删除历史证据 | 可打开原件、删除未确认记录；已确认记录禁止删除 | BOTH |
| EVID-006 | 分析结果可见 | 打开已分析证据 | 分区展示事实、推断、不确定项、教学判断和建议；失败显示脱敏原因 | BOTH |
| WRONG-001 | 分类附件 | 同一道题上传七类附件 | 类型分别保存，不混淆 | AUTO |
| WRONG-002 | 原题重做边界 | 原题即时重做正确 | 最多推进到待变式验证 | AUTO |
| WRONG-003 | 错题解决 | 无提示重做、变式、间隔复测通过 | 才可标记稳定修正 | AUTO |
| WRONG-004 | 深层错因 | 重复计算错误源于条件遗漏 | 错误链能记录前置机制 | BOTH |
| GRAPH-001 | 双层图谱 | 查看知识节点 | 同时显示标准结构和个人覆盖 | BOTH |
| GRAPH-002 | 图谱联动 | 点击薄弱节点 | 可进入错题、证据、前置知识和任务 | BOTH |
| AI-001 | 事实与判断分离 | 查看 AI 复盘 | 明确区分已确认事实、判断和待确认 | BOTH |
| AI-002 | 结构校验 | 模型返回非法 JSON | 不写库，进入重试或人工修正 | AUTO |
| AI-003 | 降级运行 | AI 服务不可用 | 核心计划与掌握规则仍可运行 | AUTO |
| AI-004 | 提示词版本 | 保存 AI 草稿 | 记录模型、提示词版本、时间和来源 | AUTO |
| AI-005 | Provider 密钥隔离 | 调用 DeepSeek/兼容接口 | Key 与 base64 原件不进入数据库、日志和前端响应 | AUTO |
| AI-006 | 不支持输入失败关闭 | 真实 Provider 分析 PDF | 记录脱敏失败并进入待修正，不伪造识别结果 | AUTO |
| DATA-001 | 新库初始化 | 空目录首次启动 | 数据库和目录正确建立 | AUTO |
| DATA-002 | 旧数据迁移 | 导入原型 localStorage JSON | 实体转换、错误报告和回滚可用 | AUTO |
| DATA-003 | 自动备份 | 数据库迁移前 | 强制创建并校验备份 | AUTO |
| DATA-004 | 恢复一致性 | 恢复任一有效备份 | 数据库、文件和清单哈希一致 | AUTO |
| DATA-005 | 环境隔离 | 开发测试运行 | 不读写正式数据目录 | AUTO |
| SEC-001 | 密钥安全 | 搜索构建产物和日志 | 无完整 API Key | AUTO |
| SEC-002 | 本地监听 | 启动本地服务 | 默认仅监听 127.0.0.1 | AUTO |
| SEC-003 | 上传校验 | 上传伪装图片或路径穿越名 | 拒绝并记录安全事件 | AUTO |
| UI-001 | 五个入口 | 桌面和手机打开 | 今日、规划、学习、进度、设置完整可达 | AUTO |
| UI-002 | 移动端题目完整 | 360px 宽查看长题目 | 无关键内容截断和强制宽表 | BOTH |
| UI-003 | 下一步明确 | 打开任一主要页面 | 有清晰主操作，不堆叠大量按钮 | HUMAN |
| REL-001 | 发布门禁 | 创建发布候选 | CI、审查、迁移和恢复测试全部通过 | AUTO |
| REL-002 | 回滚 | 模拟升级失败 | 可恢复旧程序、数据库和文件 | AUTO |
