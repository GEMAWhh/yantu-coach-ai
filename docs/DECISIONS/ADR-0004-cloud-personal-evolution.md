# ADR-0004：演进为云端个人版

- 状态：已批准
- 日期：2026-07-15
- 决策：正式产品从本地单用户原型演进为云端个人版，保留模块化单体、确定性学习规则和 AI 草稿确认边界。
- 第一阶段范围：允许独立部署的 Vue 前端连接 FastAPI API；后端仅接受明确配置的前端 Origin。
- 后续范围：在独立 ADR 和迁移报告中确定身份认证、持久化数据库、对象存储、备份恢复与部署供应商。
- 不采用：把演示数据当作正式数据；无认证公开 API；通配 CORS；在一次迁移中同时替换认证、数据库和文件存储。
- 原因：用户需要通过网址在电脑与手机使用并保存个人学习数据，同时现有核心闭环和测试资产应继续复用。
- 后果：本地模式继续可运行；云端写接口在认证落地前不得开放给公网；SQLite 到云数据库的迁移必须单独测试和审查。
