# ADR-0005：云端个人访问密钥

- 状态：已批准
- 日期：2026-07-15
- 决策：云端个人版第一阶段使用高熵个人访问密钥保护 API。服务端只保存 SHA-256 摘要，浏览器只在当前 `sessionStorage` 会话保存原始密钥，并通过 Bearer Header 发送。
- 公开端点：健康检查、API 元数据、OpenAPI 文档；其余业务端点默认受保护。
- 不采用：把密钥写入 Vite 环境变量、仓库、URL 或日志；通配匿名访问；在此阶段引入多用户账号表和第三方身份供应商。
- 原因：产品当前是单用户云端个人版，需要先以最小可审查边界阻止匿名访问，再独立演进为完整账号体系。
- 后果：生产环境缺少 `YANTU_AUTH_TOKEN_SHA256` 时启动失败；访问密钥应至少 32 个随机字符；后续多用户登录必须替换此方案并增加会话撤销、速率限制和账号恢复。
