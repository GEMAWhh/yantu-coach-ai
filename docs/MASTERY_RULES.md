# 掌握状态机与学习科学规则 V1

机器可执行配置见 `config/mastery_rules.v1.yaml`。本文是人类可读的业务契约。

## 1. 状态

0. 未学习
1. 已接触
2. 初步理解
3. 可回忆
4. 基础应用
5. 变式应用
6. 综合迁移
7. 稳定掌握
8. 掌握衰退

“掌握衰退”是异常状态；补救后回到最近一个通过的正常阶段。

## 2. 证据类型

| 证据 | 可支持 | 不可单独证明 |
|---|---|---|
| 阅读/听课/看解析 | 已接触 | 回忆和应用 |
| 自我解释 | 初步理解 | 稳定解题 |
| 闭卷回忆 | 可回忆 | 变式与迁移 |
| 基础题 | 基础应用 | 迁移与保持 |
| 变式题 | 变式应用 | 综合识别和长期保持 |
| 混合/综合题 | 综合迁移 | 长期保持 |
| 间隔测试 | 保持证据 | 不能替代理解训练 |
| 原题即时重做 | 错题修正中间步骤 | 错题已解决 |

## 3. 默认推进门槛

阈值是首版可调默认值，不是永久真理；任何调整必须新建规则版本。

- 已接触：存在有效输入行为证据。
- 初步理解：自我解释 ≥ 70，能说明定义、适用条件和用途。
- 可回忆：闭卷回忆 ≥ 70，关键要素完整，提示等级 ≤ 1。
- 基础应用：至少 4 题，正确率 ≥ 75%，关键步骤独立完成。
- 变式应用：至少 3 道非原题变式，正确率 ≥ 70%。
- 综合迁移：至少 2 道混合/综合题，正确率 ≥ 65%。
- 稳定掌握：至少两个不同时间点；回忆 ≥ 80、基础 ≥ 80、变式 ≥ 75、迁移 ≥ 70，且无未处理重复深层错因。

## 4. 转换限制

- 默认只允许逐级推进；
- 导入历史数据可以创建初始阶段，但必须标记 `imported_unverified`；
- 任何推进必须引用证据 ID；
- 任务勾选、资料整理、照片上传不能直接推进；
- 样本不足时，即使正确率高也不能推进；
- 依赖明显提示的结果降低证据权重。

## 5. 回退规则

| 失败 | 回退 | 补救 |
|---|---|---|
| 自我解释含糊 | 初次理解 | 对比概念、重述适用条件 |
| 闭卷回忆失败 | 初步理解/可回忆训练 | 短时复习后无提示回忆 |
| 基础题连续错误 | 前置诊断/基础练习 | 补前置、拆步骤、低变异题 |
| 原题会做但变式失败 | 变式训练 | 对比题组、改变条件 |
| 变式会做但综合题不会 | 综合迁移训练 | 方法选择、限时识别 |
| 间隔测试失败 | 最近通过阶段 | 缩短间隔并重新验证 |
| 同一深层错因重现 | 错因修正/前置诊断 | 错误链、原题和新题双验证 |

## 6. 错题解决标准

最低要求：

1. 能解释原错因；
2. 隔日或更晚无提示重做正确；
3. 至少完成一组同类变式；
4. 后续间隔复测通过；
5. 若属于方法选择或迁移问题，需额外迁移验证。

## 7. 证据聚合

- 保留原始证据，不只保存最终分数；
- 采用最近表现与间隔保持的加权聚合；
- 重复深层错因具有否决或强降权作用；
- 高把握度但做错视为错误自信，缩短复习间隔；
- 同一题的连续即时重做不视为独立样本。

## 8. 审计

每次判定保存：

```text
previous_stage, new_stage, evidence_ids, rule_version,
computed_metrics, blocking_reasons, transition_reason,
created_at, actor_type
```

## 9. 当前实现边界

- 状态机按 `mastery-v1.0.0` 逐级推进，不允许跳级。
- 证据与快照分别落库到 `mastery_evidence`、`mastery_snapshots`。
- 阻塞不会创建新快照；状态变化、回退和衰退会创建快照。
- 稳定掌握后的间隔测试失败进入 `掌握衰退`。
- 重复深层错因会回退到 `基础应用` 并返回高优先级补救信息。
