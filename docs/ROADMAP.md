# AI 主导研发路线图

## 阶段 0：研发基础设施

完成仓库、分支保护、Issue/PR 模板、CI、治理脚本、环境隔离和技术骨架。

退出条件：任一最小改动完整经历 Issue → PR → CI → 独立审查 → 合并。

## 阶段 1：Vue 原型迁移

保留现有视觉和五个入口，拆分组件、路由、状态和模拟 API。

退出条件：桌面及手机无退化；主要页面有 Playwright 截图基线。

## 阶段 2：正式数据层

FastAPI、SQLite、SQLAlchemy、Alembic、文件目录、审计、备份和 localStorage 导入。

退出条件：初始化、升级、失败回滚、备份恢复全部自动测试通过。

## 阶段 3：最小学习闭环

周目标、今日任务、任务结果、掌握状态机、回退、间隔复习和用时校准。

退出条件：无 AI 服务时完整闭环可用，验收矩阵对应项全通过。

进度页薄弱节点已可由用户确认后生成补救任务，并在规划与今日页面继续执行；任务完成仍需独立证据判定掌握。

## 阶段 4：五层计划联动

学期、季度、月、周、日的上下级关系、风险和再计算。

## 阶段 5：每日证据

多图上传、OCR/AI 草稿、用户确认和正式记录联动。Fake Provider 已验证治理流程；DeepSeek 作为首个真实图片 Provider，百炼、硅基流动等通过 OpenAI-compatible 适配层保留接入口。PDF 转图/OCR 和真实模型黄金集评测仍待完成。

## 阶段 6：错题中心

七类附件、结构化题目、深层错因、无提示重做、变式和间隔复测。

## 阶段 7：知识图谱与资料检索

标准知识树、个人覆盖、图谱联动、PDF 预览、全文检索和带页码回答。学习页已具备资料上传、打开、
删除及知识点新增、修改、删除入口；关系编辑、全文检索和带页码回答仍待完成。

## 阶段 8：AI 总教练与联网校准

统一导师输出、外部信息来源管理、个人数据优先和模型评测。在自动分析达到可靠性门槛前，
先提供版本化 Prompt 工具箱，由用户复制内容并自行前往外部 LLM Chat，第三方回答不自动回写。

## 阶段 9：Tauri 正式发布

Windows 安装包、自动启动本地后端、安全密钥、升级和恢复。
