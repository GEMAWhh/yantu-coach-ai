# 阶段3：最小学习闭环端到端验收


## 背景

阶段3必须证明核心闭环不是若干孤立页面和接口。

## 目标

建立从周目标、今日计划、任务结果、掌握推进、复习到回退的 Playwright 和 API 端到端测试。

## 非目标

不新增业务功能。

## 验收标准

- [ ] 完整正常路径通过。
- [ ] 阅读任务不会错误推进掌握。
- [ ] 抽测失败会回退并生成补救候选。
- [ ] 单科过滤和机动时间在 UI 可见。
- [ ] 备份恢复后核心流程继续可用。

## 测试要求

至少覆盖正常、失败、重复提交和移动端四组场景。

## 回滚

测试代码可独立回滚，不影响业务数据。
