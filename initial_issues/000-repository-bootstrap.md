# 阶段0：建立仓库骨架与强制门禁


## 背景

当前只有单文件 HTML 原型和研发规范，需要先建立可供多个 AI 安全协作的工程骨架。

## 目标

建立 `main/develop` 分支策略、Vue/FastAPI 目录骨架、基础 CI、本地环境隔离和开发命令。

## 非目标

不迁移页面、不设计业务数据库、不实现学习功能。

## 允许修改范围

仓库根目录、`.github/`、`apps/web/`、`apps/api/`、基础配置与文档。

## 验收标准

- [ ] `apps/web` 可启动最小 Vue 3 + TypeScript 页面。
- [ ] `apps/api` 可启动 FastAPI `/health`。
- [ ] dev/test/prod 数据目录配置严格分离。
- [ ] CI 执行格式、类型、单元测试和构建。
- [ ] README 写明本地启动命令。

## 测试要求

前后端各至少一个通过测试；CI 在空白环境可稳定通过。

## 回滚

删除新增工程目录并恢复本执行包初始提交。

## 依赖

无。
