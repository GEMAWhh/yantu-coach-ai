# 阶段2：本地文件存储、哈希、备份与恢复


## 背景

图片、PDF 和数据库必须形成一致的可恢复数据集。

## 目标

实现文件服务、SHA-256、原始/派生目录、备份 manifest、校验和恢复。

## 非目标

不实现 OCR、PDF 解析和用户上传 UI。

## 验收标准

- [ ] 同一文件去重且引用安全。
- [ ] 路径穿越和伪装类型被拒绝。
- [ ] 备份同时包含数据库、文件和 manifest。
- [ ] 恢复前自动备份当前状态。
- [ ] 恢复后哈希和引用一致。

## 测试要求

重复文件、损坏备份、缺失文件、恢复中断和正式目录保护。

## 回滚

恢复本任务前数据库和文件备份。
