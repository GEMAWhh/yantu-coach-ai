# 阶段3：周目标、今日任务与结果分离


## 背景

需要建立最小的周目标→今日任务→真实结果链路。

## 目标

实现 goals、tasks、task_results、基础 API 和 Vue 页面联动。

## 非目标

不实现五层完整再计算，不实现智能排序。

## 验收标准

- [ ] 周目标可创建并显示进度。
- [ ] 今日任务可追溯来源。
- [ ] 任务状态和任务结果严格分离。
- [ ] 结果保存真实用时、正确率、把握度和问题。
- [ ] 完成任务不直接改变掌握阶段。

## 测试要求

API、事务、重复提交、版本冲突和移动端 E2E。

## 回滚

删除新任务数据或恢复迁移前备份。
