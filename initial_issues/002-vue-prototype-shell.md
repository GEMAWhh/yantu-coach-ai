# 阶段1：将原型迁移为 Vue 五页应用外壳


## 背景

当前单 HTML 已形成较成熟视觉，但业务、状态和 DOM 操作混写。

## 目标

迁移 AppLayout、桌面侧栏、移动底栏及今日/规划/学习/进度/设置五页，使用模拟数据保持视觉和文案。

## 非目标

不连接正式后端，不实现真实业务规则，不重设计视觉。

## 验收标准

- [ ] 五个一级入口完整可达。
- [ ] 桌面布局和 360px 手机布局无关键溢出。
- [ ] 设计 token 集中管理。
- [ ] 页面不使用 innerHTML 拼接主结构。
- [ ] 每页有 Playwright 截图基线。

## 测试要求

路由 E2E、桌面和手机截图、键盘导航基本检查。

## 回滚

保留 references 原型，删除新页面实现即可。
