# 阶段2：原型 localStorage 数据迁移工具


## 背景

当前 HTML 原型使用 localStorage，正式系统需支持一次性安全导入。

## 目标

实现 JSON 上传、Schema 校验、迁移预览、实体映射、幂等提交和迁移报告。

## 非目标

不把缺少证据的历史掌握度直接标为稳定掌握。

## 验收标准

- [ ] 可导入原型有效 JSON。
- [ ] 未识别字段显示在预览和报告。
- [ ] 掌握数据标记 imported_unverified。
- [ ] 正式导入事务化且幂等。
- [ ] 导入失败不留下部分数据。

## 测试要求

有效、缺字段、损坏、重复提交和超大数据测试。

## 回滚

删除该次导入批次或恢复导入前备份。
