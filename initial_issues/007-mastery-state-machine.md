# 阶段3：掌握证据与九阶段状态机


## 背景

核心产品价值是判断是否真正掌握，而不是任务勾选。

## 目标

按 mastery-v1.0.0 实现证据记录、推进门槛、阻塞原因、快照和回退。

## 非目标

不实现 AI 判定，不实现完整复习调度和错题中心。

## 验收标准

- [ ] 阅读最多进入已接触。
- [ ] 无闭卷证据不能进入可回忆。
- [ ] 样本和正确率不足不能进入对应阶段。
- [ ] 稳定掌握后失败可回退。
- [ ] 所有变化保存证据和规则版本。

## 测试要求

验收矩阵 MAST-001 至 MAST-009 全部自动化。

## 回滚

保留原始证据，回滚状态机代码和规则版本，不删除历史事件。
