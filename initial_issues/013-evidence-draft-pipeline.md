# 阶段5预备：每日证据草稿治理（Fake AI）


## 背景

真实模型接入前，应先验证“上传→草稿→确认→正式记录”的治理边界。

## 目标

实现多文件上传、AIJob、Fake Provider、Schema 校验、草稿编辑、确认事务和拒绝。

## 非目标

不接真实 OCR/多模态模型，不自动识别图片内容。

## 验收标准

- [ ] 多图关联同一证据记录。
- [ ] Fake Provider 输出符合 evidence schema。
- [ ] 未确认不改变正式记录、计划和掌握。
- [ ] 确认操作幂等并有审计。
- [ ] 非法 JSON 进入失败/修正状态。

## 测试要求

EVID-001 至 EVID-004、AI-002 和 AI-003。

## 回滚

保留原图和草稿，禁用确认入口即可。
