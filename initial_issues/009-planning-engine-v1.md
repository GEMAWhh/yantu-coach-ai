# 阶段3：可解释的今日计划引擎 V1


## 背景

每日计划必须读取时间、精力、周目标、掌握阶段、前置知识和到期复习。

## 目标

实现候选任务评分、硬约束、机动时间、单科过滤、低精力降级和解释分项。

## 非目标

不做机器学习优化，不联网参考他人进度。

## 验收标准

- [ ] 计划保留至少配置比例机动。
- [ ] 单科过滤严格生效。
- [ ] 前置不满足的高阶任务被阻止或降级。
- [ ] 低精力不安排高认知任务。
- [ ] 每项任务有评分来源和未入选原因。

## 测试要求

验收矩阵 PLAN-004 至 PLAN-008；固定随机数和固定时钟。

## 回滚

回退到手动任务选择，保留已有任务数据。
